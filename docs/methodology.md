# Методология (черновик главы 2)

## 1. Сбор данных

### Источник
**Uzum Market** (uzum.uz) — крупнейший маркетплейс Узбекистана.

### Технические особенности API
- Публичный REST `api.uzum.uz/api/v2/product/{id}` отдаёт карточку товара + 1 топ-отзыв
- GraphQL `graphql.uzum.uz` отдаёт **полный список отзывов**, но требует JWT
- JWT-токен (anonymous) выдаётся автоматически при загрузке uzum.uz, хранится в cookie `access_token`
- Сама страница `uzum.uz` за Yandex SmartCaptcha — нужен реальный браузер

### Технологии сбора
1. **httpx** — лёгкий REST-клиент для metadata (см. `scraper/uzum/client.py`)
2. **Playwright + chromium** — для GraphQL-запросов с автоматическим JWT
   (см. `scraper/uzum/browser_client.py`). Используем `APIRequestContext`
   потому что Nuxt оверрайдит `window.fetch` и блокирует прямые вызовы из контекста страницы.

### GraphQL операция Feedbacks
```graphql
query Feedbacks($productPageId: Int!, $filters: [FeedbackFilterType!],
                $page: Int!, $size: Int!, $sort: FeedbackSortType!) {
  productPage(id: $productPageId) {
    feedbacks(filters: $filters, page: $page, size: $size, sort: $sort) {
      id, content, rating, customerName, dateCreated, datePublished,
      pros, cons, anonymous, reply { content, dateCreated }
    }
  }
}
```

### Объём датасета
- **Этап 1 (httpx topFeedback):** 190 отзывов с 190 товаров (1 топ-отзыв × N товаров)
- **Этап 2 (Playwright full):** ~5000 отзывов с топ-50 товаров

## 2. Препроцессинг

## 3. Sentiment Analysis (baseline)

### Модель
`tabularisai/multilingual-sentiment-analysis` — fine-tuned XLM-RoBERTa, 22 языка
включая ru/uz. Скачивается с HuggingFace, ~1ГБ.

### Метки
3-классная схема: `positive` / `neutral` / `negative` (нормализуем выход модели).

### Результат на 190 отзывах (этап 1)
- 65.8% positive
- 17.9% neutral
- 16.3% negative
- **Согласованность с rating-звёздами: 68.4%**

### Главное наблюдение для диплома
**Звёзды ≠ тональность.** 21 отзыв с 5★ модель классифицировала как «негатив»:
- *«К качеству претензий нет, но доставка была долгой»* — 5★, текст ругает доставку
- *«Не соответствует описанию»* — 3★, явный негатив
- Это и есть **ценность сентимент-анализа** против rating-фильтра.

## 4. Aspect-Based Sentiment Analysis (ABSA)

### Подход — keyword-based extraction + sentence-level sentiment

1. **Словарь аспектов**: `Доставка / Цена / Качество / Упаковка`
   с 20+ корнями каждый на ru/uz_lat/uz_cyr (`apps/analysis/aspects_seed.py`).
2. **Сегментация**: текст бьётся на предложения по `[.!?;\n]`.
3. **Поиск**: для каждого предложения проверяем все аспекты по подстроке-корню.
4. **Локальный sentiment**: matched-предложение прогоняется через ту же модель.
5. **Агрегация**: на товар × аспект — упоминание с максимальным score.

### Итог по 190 отзывам

| Аспект | Позитив | Нейтрал | Негатив | Всего |
|---|---|---|---|---|
| Качество | 62 | 12 | 8 | 82 |
| Доставка | 9 | 5 | 4 | 18 |
| Цена | 7 | 2 | 2 | 11 |
| Упаковка | 5 | 2 | 1 | 8 |

**119 упоминаний** на 190 отзывов = на каждый второй отзыв находится аспект.

### Кейс — расхождение overall vs aspect

Кастрюля Kukmara Trendy Style (4.9★, donut позитив):
- Качество: позитив ✅
- Доставка: негатив ❌
- Цена: негатив ❌

Покупатель доволен товаром, но магазин — нет. Это и есть **главная польза ABSA**
для бизнес-выводов: rating говорит «всё ок», ABSA показывает что улучшать.

## 5. Ограничения мультиязычных моделей на узбекском

### Эксперимент

После сбора и разметки полного датасета мы отделили узбекские отзывы (uz/uz_cyr/kaa)
и пересчитали метрики отдельно для русского и узбекского сегментов.

| Метрика | Русский (≈2500 отзывов) | Узбекский (1709 отзывов) |
|---|---|---|
| Согласованность модель ↔ rating | **68.4%** | **16.7%** |
| Доля 5★, помеченных как `negative` | 16% | 21% |
| Доля 5★ → `neutral` | 19% | 64% |

Падение в **4 раза**.

### Где модель ошибается

`tabularisai/multilingual-sentiment-analysis` декларирует поддержку 22 языков
включая узбекский, но на реальных отзывах не распознаёт **типичные позитивные
маркеры узбекского языка**:

| Слово (uz) | Перевод | Что говорит модель |
|---|---|---|
| `zo'r` / `zoʻr` / `zor` | «классно», «отлично» | neutral / negative |
| `ajoyib` | «прекрасно» | neutral |
| `tavsiya qilaman` | «рекомендую» | neutral |
| `effekti zor` | «эффект отличный» | negative |
| `judayam yaxshi` | «очень хорошо» | neutral |

Модель срабатывает только на словах из английского/русского пула —
`super`, `OK`, `ne ploho` (написанное латиницей), эмодзи 👍.

### Вывод

Готовая multilingual-модель **не подходит** для production-инструмента на
узбекском рынке. Это и есть бизнес-обоснование fine-tune'а — основная
прикладная глава диплома.

### План для расширенной части
1. **Fine-tune** XLM-RoBERTa на ~500 вручную размеченных uz-отзывах
2. **Семантический ABSA** — заменить keyword-search на embedding-similarity
   (sentence-transformers + cosine с прототипными «определениями» аспектов)
3. **Confidence-фильтр** — отбрасывать предсказания где `score < 0.55`
4. **Расширить корпус** через Asaxiy + Texnomart для cross-marketplace generalization
